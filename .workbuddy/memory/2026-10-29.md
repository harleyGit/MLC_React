## 运维管理四页面 UI 重构（对标字节/B站风格）

- 需求：按《角色权限设计.md》重构运维管理的管理员管理、用户管理、角色管理、权限管理四个页面，组件优先自建。
- 新增通用组件（`src/components/`）：
  - `hg_stat_card`：顶部 KPI 指标卡（色调 tone、图标、suffix）。
  - `hg_status_tag`：圆点胶囊状态标签（success/error/warning/info/neutral）。
  - `hg_avatar`：按名称哈希取色的文字头像（无图时）。
  - `hg_page_header`：页面头（标题+描述+右侧操作区）。
- 页面重构：
  - `admin_list`：页头+指标卡+提示条；表格改为头像+姓名主列、ID 等宽字体、状态标签；VM 增加 `getStatusTone`/`countByStatus`。
  - `user_permission`：同上风格；"分配角色"弹窗改用 HGModalPage + HGDetailGrid + 卡片式角色多选（含筛选、已选计数、清空）。
  - `role_list`：角色徽标列（哈希取色）+ 描述空态 + 时间 tabular-nums；编辑/删除弹窗改为 CSS module 表单样式；VM 增加 `getRoleBadgeColor`。
  - `role_permission`：重构为左右布局——左侧角色卡片列表（可搜索），右侧权限按"业务域→资源→权限项"分组勾选；权限编码转换为 `业务域:资源:操作`；按关键词输出风险等级标签（极高/高/中）；支持分组全选、父节点展开、二次防误清空；MOCK 数据增加运维管理域与安全审计域。
- 验证：eslint 通过；vite build（输出 /tmp）通过；用临时预览页 + Chrome headless 截图核对四页面与弹窗视觉，临时文件已删除。
- 注意：HGModalPage 支持 onOk/onCancel/okText/okType/footer 契约；HGCheckbox 根节点是 label，行内布局可用 `.permRow label { flex-shrink: 0 }` 控制压缩。
